# Formulário para clientes (WhatsApp)

Cola e envia. Versão em espanhol (audiência UCEBOL).

---

```
📚 *Formulario, Trabajo de Investigación UCEBOL*

Hola! Para poder armar tu trabajo, necesito que me llenes esto:

1️⃣ *Tipo de trabajo*
   ( ) Ensayo Académico (1er año)
   ( ) Perfil de Investigación Básico (2do año)
   ( ) Perfil de Investigación Intermedio (3er año)
   ( ) Artículo Original (avanzado)

2️⃣ *Datos del cabecero*
   • Nombre completo,
   • Asignatura/Materia,
   • Docente (con título, Dr/Dra/Lic),
   • Semestre/Gestión (ej, Gestión I),
   • Año,
   • Grupo, (opcional)

3️⃣ *Tema*
   Sé específico, no genérico.
   Ejemplo bueno, "fisiopatología de la diabetes mellitus tipo 2"
   Ejemplo flojo, "diabetes"

4️⃣ *Tu enfoque* (opcional pero MUY recomendado)
   Escribime cómo estás pensando el trabajo, qué ángulo querés darle, si tenés alguna hipótesis personal, qué tono querés.
   Esto le da autenticidad y evita que parezca genérico.

   Ejemplo,
   "Quiero enfocar en complicaciones renales, tono crítico al tratamiento actual, en la conclusión dejar claro que estoy a favor del rastreo precoce."

5️⃣ *Solo si es Perfil Básico o Intermedio*
   • Población a estudiar,
   • Lugar del estudio,
   • Tipo, descriptivo o analítico,

6️⃣ *Solo si es Artículo Original*
   • Lista de autores con afiliación,
   • ¿Ya tenés datos del estudio? sí/no,

📌 Plazo de entrega que necesitás,

Cualquier duda me decís 👍
```
